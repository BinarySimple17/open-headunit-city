# Open Headunit — fork for City

Форк проекта [andreknieriem/open-headunit](https://github.com/andreknieriem/open-headunit) —
Android-приложения, превращающего планшет или головное устройство в ресивер Android Auto
(возрождённая версия оригинального [headunit](https://github.com/mikereidis/headunit) Майкла Рейда).

Этот форк адаптирован под головные устройства **Geely/ECARX**: добавлена панель управления
климатом поверх проекции и мок-бэкенд машины для разработки на обычном эмуляторе.

## Что добавлено относительно upstream

- **Климат-панель в проекции** (`app/.../geely/hvac`): круглая якорная кнопка в правом верхнем
  углу, по тапу — колонка кнопок (сиденья, руль, лобовое/заднее стекло, MAX, рециркуляция);
  кнопка сидений раскрывает ряд из 4 зон (водитель, пассажир, задние левое и правое, уровни 0–3).
  Кнопки — иконки, тонируемые статусной палитрой (серый — выкл, зелёный/оранжевый/красный —
  уровни 1/2/3); цвета следуют дню/ночи проекции. Состояния читаются из машины при старте
  панели и опрашиваются каждые 2 с — внешние включения/выключения отражаются сами.
- **Автоподогрев**: долгий тап на сиденье или руле включает авто-режим через выделенные
  свойства VHAL — с текущим уровнем или настроенным; повторный долгий тап гасит подогрев
  полностью. Активный auto помечен значком «A».
- **Бэкенд машины** — автомобильные API через reflection (без вендорских классов в APK);
  в debug-сборках без automotive-прошивки панель переключается на отдельное
  приложение-мок `:mockcar` через AIDL — можно разрабатывать и тестировать панель на
  обычном эмуляторе.
- **Вкладка GEELY** в настройках: режим панели (только якорь / всегда), таймаут скрытия
  иконок, модель авто, уровни автоподогрева, подробный лог (`HVAC_Log_*.txt` в папке
  Download). Изменения применяются общей кнопкой «Сохранить».
- **`contract/`** — публичная поверхность интентов (`AutomationReceiver`,
  `HeadUnitIntent.kt`) для внешних автоматизаций (Tasker/MacroDroid/adb).

## Сборка

- JDK 17+, Android SDK (compileSdk 36), NDK `29.0.14206865` + CMake `3.22.1`
  (пины — в `app/build.gradle.kts`); Gradle wrapper 8.14.4.
- Сборка приложения: `./gradlew :app:assembleGithubDebug`
  (APK — `app/build/outputs/apk/github/debug/`).
- Мок-приложение для эмулятора: `./gradlew :mockcar:assembleDebug`.
- Юнит-тесты: `./gradlew :app:testGithubDebugUnitTest :mockcar:testDebugUnitTest`.
- minSdk 21 (github-флейвор), приложение: `com.andrerinas.headunitrevived.*`,
  namespace/интенты: `com.andrerinas.openheadunit.*` — не путать (см. `contract/README.md`).

## Соединение с телефоном

Все способы upstream работают: USB, Wi-Fi Direct/hotspot, «головной сервер» Android Auto
(на телефоне: Настройки AA → «Версия» ×10 → ⋮ → **Start headunit server**), Wireless Helper,
Self-Mode. Подробности — в [upstream-README](https://github.com/andreknieriem/open-headunit#readme)
и [wiki](https://github.com/andreknieriem/open-headunit/wiki).

**Проверка панели на эмуляторе** (без машины): собрать и установить оба APK
(приложение и мок), запустить мок-приложение, на телефоне включить «головной сервер»,
на хосте выполнить `adb forward tcp:5277 tcp:5277`, в приложении на эмуляторе —
режим «Сервер» и кнопка WiFi (эмулятор найдёт `10.0.2.2:5277`).
